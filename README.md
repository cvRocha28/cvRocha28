# Hi, I'm Caio Rocha

Senior Software Engineer focused on the .NET ecosystem, software architecture, modern identity and AI integration.

## About Me

I build and evolve enterprise applications with C# and .NET, with an emphasis on clear architecture, security and maintainability. My work covers enterprise systems, integrations and application modernization.

Over time my focus has moved from general software engineering toward software architecture, identity and security, and, more recently, integrating existing AI models and agents with applications, code and enterprise tooling through the Model Context Protocol (MCP).

I do not build or train AI models. My work in this area is about integration: giving agents the structured context and tools they need to be useful in real engineering workflows.

## What I'm Working On

### Modern Identity & Security

I designed and developed **AtentoID**, a modern identity and authentication solution proposed as an evolution of an enterprise identity architecture. It explores .NET 10, ASP.NET Core Identity, OpenIddict, Microsoft Entra ID, OAuth 2.0 / OpenID Connect with PKCE, MFA, Passkeys / WebAuthn, step-up authentication, multi-tenant authentication and face liveness verification with AWS Rekognition.

The project is at an advanced stage of development and has been presented to management. It remains a proposal under evaluation and is not in production.

### AI Integration & MCP

I developed **Atento.AgentSkills**, a .NET solution built on the Model Context Protocol that gives AI coding agents structured context about a codebase before they assist with development tasks. Its capabilities include codebase context generation, symbol discovery, change impact analysis and specialized tools for agents. It supports STDIO and HTTP transports, is distributed as a .NET Tool through GitHub Packages, and is built and tested with GitHub Actions and automated tests.

### Software Architecture & Developer Tooling

I am interested in code analysis, automation and tools that help developers and AI agents understand code, symbols, dependencies and the impact of changes, and in applying clean architecture to enterprise systems.
